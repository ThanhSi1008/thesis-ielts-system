Figure 3: AI Grading Pipeline

sequenceDiagram
    participant U as Student
    participant FE as Frontend
(Next.js)
    participant BE as Core Backend
(NestJS)
    participant MQ as RabbitMQ
    participant AI as AI Service
(FastAPI)
    participant DB as PostgreSQL

    Note over U,DB: Writing Grading Flow (Synchronous)
    U->>FE: Submit Writing Exam
    FE->>BE: POST /exams/sessions/:id/submit
    BE->>BE: Grade Listening/Reading
(deterministic)
    BE->>AI: POST /api/v1/writing/grade
    AI->>AI: LLM Inference
(Llama 3.3 70B, ~10s)
    AI-->>BE: JSON{criteria, bands, mistakes}
    BE->>DB: Save result + feedback
    BE-->>FE: Return complete result
    FE-->>U: Display scores & feedback

    Note over U,DB: Pronunciation Check Flow (Asynchronous)
    U->>FE: Record pronunciation
    FE->>BE: POST /pronunciation/attempt
    BE->>DB: Create attempt (PENDING)
    BE->>MQ: Publish to pronunciation-check-queue
    BE-->>FE: Return attemptId immediately
    MQ->>AI: Consume task
    AI->>AI: Download audio from MinIO
    AI->>AI: Whisper transcription (~3s)
    AI->>AI: Levenshtein scoring
    AI->>DB: UPDATE attempt (COMPLETED)
    FE->>BE: Poll GET /pronunciation/attempt/:id
    BE-->>FE: Return score + feedback
    FE-->>U: Display result

SM-2 Algorithm Flowchart

flowchart TD
    START["Card shown to user"] --> RATE["User rates: q ∈ {0,1,2,3,4,5}"]
    RATE --> CALC["Update EF: EF' = EF + (0.1 - (5-q) × (0.08 + (5-q) × 0.02))"]
    CALC --> CHECK_EF{"EF' < 1.3?"}
    CHECK_EF -- Yes --> SET_MIN["EF' = 1.3"]
    CHECK_EF -- No --> QUALITY
    SET_MIN --> QUALITY{"q < 3?"}
    
    QUALITY -- "Yes (Failed)" --> RESET["repetition = 0
interval = 1 day
state = LEARNING"]
    QUALITY -- "No (Passed)" --> REP_CHECK{"repetition?"}
    
    REP_CHECK -- "0" --> INT1["interval = 1 day"]
    REP_CHECK -- "1" --> INT6["interval = 6 days"]
    REP_CHECK -- ">1" --> INT_CALC["interval = interval × EF'"]
    
    INT1 --> INC_REP["repetition++"]
    INT6 --> INC_REP
    INT_CALC --> INC_REP
    
    INC_REP --> STATE_CHECK{"repetition > 1?"}
    STATE_CHECK -- Yes --> REVIEW_STATE["state = REVIEW"]
    STATE_CHECK -- No --> LEARNING_STATE["state = LEARNING"]
    
    RESET --> SCHEDULE["Schedule next review"]
    REVIEW_STATE --> SCHEDULE
    LEARNING_STATE --> SCHEDULE
    SCHEDULE --> END["Save to database"]
