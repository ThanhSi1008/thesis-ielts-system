# IELTS Statistics: Advanced Tab Requirements

## Core Requirements (Exactly 5)

| # | Requirement | Data Source |
|:--|:---|:---|
| 4.1 | **Question Type Accuracy Heatmap** | Aggregated `scoreData` per question type from L/R sessions |
| 4.2 | **Weak Spots Identification** | Top 3 lowest accuracy question types flagged for review |
| 4.3 | **Advanced Score Trend Line** | Average accuracy trend over the last 10 L/R sessions |
| 4.4 | **Writing AI Feedback Summary** | Aggregate band score and common penalties (`IeltsAdvancedWritingSession`) |
| 4.5 | **Speaking AI Feedback Summary** | Aggregate band score and fluency issues (`IeltsAdvancedSpeakingSession`) |

## Revamped Premium UI Concept
* **Aesthetic**: High-Tech Analytical Radar. Focus on deep-dive diagnostics.
* **Radar Spider Chart**: A stunning, futuristic radar chart overlaying Listening vs Reading question type performance. Use semi-transparent polygon fills that animate outward from the center on load.
* **Weak Spots Alerts**: Premium warning cards with a pulsating red or amber accent border. Instead of just showing the weakness, include a highly visible "Practice This Now" CTA button with a hover glow effect.
* **Score Trend Line**: A smooth, bezier-curved area chart. The fill below the line uses a soft vertical gradient. Interactive hover states snap to data points with a satisfying pop-up tooltip showing exact date and score.
