# IELTS Statistics: Intensive Tab Requirements

## Core Requirements (Exactly 5)

| # | Requirement | Data Source |
|:--|:---|:---|
| 5.1 | **Overall Mock Band Trend** | Average band score across L/R/W/S from all completed `ExamSession`s |
| 5.2 | **Individual Skill Band Trends** | Isolated band score trends for Listening, Reading, Writing, and Speaking |
| 5.3 | **Score Distribution Histogram** | Frequency count of specific band scores achieved (e.g., how many 7.0s) |
| 5.4 | **Time Management Analytics** | Average `timeTaken` per mock test compared against the 3-hour exam limit |
| 5.5 | **Best vs Worst Skill Gap** | Visual disparity between the highest and lowest performing skills |

## Revamped Premium UI Concept
* **Aesthetic**: Cinematic, Dark-Themed Analytics Console. Feels like a high-end trading dashboard for exam scores.
* **Master Trend Chart**: The main band score chart uses thick, vibrant lines over a dark background. Tooltips snap magnetically to data points with a satisfying micro-interaction, revealing the exact date and score breakdown.
* **3D Distribution Bars**: The Score Distribution histogram uses 3D-effect bar charts or cylindrical bars that rise sequentially on load, giving a sense of volume to the user's history.
* **Time Management Gauge**: An animated, segmented speedometer gauge. It sits comfortably in the green zone if the user completes tests within the optimal window, but creeps into a glowing amber/red zone if they are consistently too slow.
