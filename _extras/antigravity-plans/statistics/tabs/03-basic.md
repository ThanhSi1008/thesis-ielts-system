# IELTS Statistics: Basic Tab Requirements

## Core Requirements (Exactly 5)

| # | Requirement | Data Source |
|:--|:---|:---|
| 3.1 | **Listening Curriculum Progress** | Completion rate of Listening lessons & exercises (`IeltsBasicProgress`) |
| 3.2 | **Reading Curriculum Progress** | Completion rate of Reading lessons & exercises (`IeltsBasicProgress`) |
| 3.3 | **Writing Curriculum Progress** | Completion rate of Writing lessons & exercises (`IeltsBasicProgress`) |
| 3.4 | **Speaking Curriculum Progress** | Completion rate of Speaking lessons & exercises (`IeltsBasicProgress`) |
| 3.5 | **Overall Basic Readiness** | Aggregate completion % across all 4 skills to unlock Advanced tier |

## Revamped Premium UI Concept
* **Aesthetic**: Sleek, expanding horizontal progress bars with neon accents.
* **Skill Bars**: Four thick, rounded horizontal bars (one per skill) utilizing specific brand colors (e.g., Listening = vibrant pink, Reading = electric blue). The filled portion of the bar has a subtle, continuous shimmer animation.
* **Accordion Drill-Down**: Instead of taking the user to a new page, clicking a skill bar expands a smooth accordion directly below it. This reveals a micro-timeline of the most recently completed lessons in that skill, entering with a cascading slide-in animation.
* **Readiness Badge**: A centralized, premium metallic-styled badge that "levels up" visually (e.g., Bronze -> Silver -> Gold) as the overall aggregate progress approaches 100%.
