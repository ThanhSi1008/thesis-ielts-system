# IELTS Statistics: Foundation Tab Requirements

## Core Requirements (Exactly 5)

| # | Requirement | Data Source |
|:--|:---|:---|
| 2.1 | **Vocabulary Mastery Flow** | `FoundationVocabProgress` (words learned vs total available) |
| 2.2 | **Grammar Completion Metrics** | `FoundationGrammarProgress` (units completed vs available) |
| 2.3 | **Pronunciation Articulation Stats** | `FoundationPronunciationProgress` (sounds mastered / practicing / new) |
| 2.4 | **Average Foundation Accuracy** | Combined average quiz scores from Vocab and Grammar |
| 2.5 | **Foundation Time Balance** | Distribution of effort across Vocab, Grammar, and Pronunciation |

## Revamped Premium UI Concept
* **Aesthetic**: Dynamic 3D-styled Card Carousel/Grid. No more static tables.
* **Liquid Progress Visuals**: Replace flat donut charts with animated SVG "liquid fill" or wave progress indicators inside circular containers to represent mastery levels.
* **Interactive Cards**: The Vocab, Grammar, and Pronunciation summary cards feature micro-animations. Hovering slightly lifts the card with a soft shadow and smooth transition.
* **Flippable Details**: Clicking or hovering a module card triggers a 3D flip animation, revealing deeper insights on the back (e.g., the specific grammar rule the user is struggling with, or their most mispronounced sound).
