\justify
\begin{sloppypar}
IELTS is a globally recognized English proficiency certification. However, existing preparation platforms often specialize in a single skill, rely on costly human tutoring, or lack automated scoring aligned with official rubrics. This thesis presents \textbf{IELTS Master English (Lexon)} — a comprehensive web and mobile platform for IELTS learners aiming for Band 4.0 to 7.5+.

The system utilizes an event-driven modular monolith architecture, consisting of a NestJS backend (18 modules), a FastAPI AI worker communicating via RabbitMQ, a Next.js web portal, and an Expo React Native mobile app. The infrastructure leverages Supabase, Upstash Redis, CloudAMQP, and Cloudinary on a GCP VM. Key features include a four-tier learning track, 44-phoneme IPA pronunciation scoring, Gemini-powered automated Writing/Speaking grading, full Mock Tests, Shadowing/Dictation, an FSRS spaced repetition vocabulary lab, personalized roadmaps, gamification, and VNPay integration.

Testing confirms that the automated grading pipeline returns evaluation results within 5–10 seconds, ensuring high consistency across platforms. The project demonstrates the feasibility of combining modular architecture with generative AI to provide a comprehensive, interactive, and cost-effective IELTS preparation solution.
\end{sloppypar}
