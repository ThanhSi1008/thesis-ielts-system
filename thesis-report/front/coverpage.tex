\begin{sloppypar}
IELTS is a globally recognized English proficiency certification. However, existing preparation platforms often specialize in a single skill, depend on costly human tutors, or lack automated scoring aligned with official IELTS rubrics. This thesis presents \textbf{IELTS Master English (Lexon)} --- a comprehensive learning and test preparation system for learners aiming for Band 4.0 to 7.5+, delivered on both web and mobile.

The system utilizes an event-driven modular monolith architecture: a NestJS backend (18 feature modules), a FastAPI AI worker communicating asynchronously via RabbitMQ, a Next.js web portal on Cloud Run, and a React Native Expo mobile application. The data tier leverages managed cloud services (Supabase PostgreSQL, Upstash Redis, CloudAMQP, and Cloudinary) running on a GCP VM behind an Nginx reverse proxy. Key features include a four-tier learning track (Foundation, Basic, Advanced, Intensive) covering all four IELTS skills; 44-phoneme IPA pronunciation scoring using a weighted formula; automated Writing and Speaking grading via the Gemini 2.5 Flash API following the four official IELTS criteria; full-length Mock Tests; Shadowing/Dictation; an FSRS spaced repetition vocabulary lab; placement tests with personalized roadmaps; gamification; and VNPay subscription integration.

Testing confirms that the asynchronous grading pipeline returns Writing and Speaking results within 5--10 seconds, and the platform runs consistently across web and mobile. The project demonstrates the feasibility of combining a modular architecture with generative AI to offer Vietnamese learners a comprehensive, interactive, and cost-effective IELTS preparation solution.
\end{sloppypar}
