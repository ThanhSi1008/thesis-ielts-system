\begin{sloppypar}
IELTS (International English Language Testing System) is one of the most widely recognized English proficiency certifications in the world, with over 3.5 million test-takers annually. However, most existing preparation platforms specialize in a single skill (e.g., ELSA Speak for pronunciation), depend on human tutors at high cost (e.g., Cambly), or lack automated AI scoring aligned with the four official IELTS rubrics for Writing and Speaking. Few products integrate placement testing, a personalized study path, four-skill practice, and AI-based assessment into a single multi-platform solution. This thesis presents the design and implementation of an IELTS learning and test preparation system targeting Vietnamese learners aiming for Band 4.0 to 7.5+, delivered on both web and mobile.

The system follows an event-driven modular monolith architecture: a NestJS 10 backend organized into 17 feature modules, a dedicated FastAPI AI worker communicating asynchronously through RabbitMQ, a Next.js 14 web portal deployed on Google Cloud Run, and a React Native Expo mobile application. The data tier relies on managed cloud services --- Supabase (PostgreSQL 16 with PgBouncer), Upstash (Redis with TLS), CloudAMQP (RabbitMQ over AMQPS), and Cloudinary (media storage and CDN) --- while backend containers run on a single GCP VM behind an Nginx reverse proxy with Let's Encrypt TLS. Key features include a four-tier learning track (Foundation, Basic, Advanced, Intensive) covering all four IELTS skills; 44-phoneme IPA pronunciation scoring using a weighted formula combining phoneme edit-distance, Whisper confidence, and text similarity; automated Writing and Speaking grading via the Gemini 2.5 Flash API following the four official IELTS criteria; full-length Mock Test simulation with timed countdown and band-score conversion; YouTube-based Shadowing and Dictation with AI transcription; a Vocab Lab built on the FSRS spaced repetition algorithm with Lexon AI card prefill and community deck sharing; a placement test that drives a personalized weekly study roadmap; gamification (XP, achievements, streaks); a community feed; and a three-tier subscription system (Free, Premium, Pro) integrated with VNPay.

Integration testing on the development environment confirms that the asynchronous grading pipeline returns Writing and Speaking results within 5--10 seconds, the modular monolith deploys reliably through GitHub Actions CI/CD, and the platform delivers consistent functionality across web and mobile clients. The project demonstrates the feasibility of combining a modular backend architecture with generative AI services to build a comprehensive IELTS preparation environment, narrowing the gap left by single-skill or human-only solutions currently available to Vietnamese learners.
\end{sloppypar}
